頁面瀏覽量的變化

造訪次數和頁面瀏覽量有什麼不同？

例如，同一個分頁裡進入網站、看首頁再看文章，通常算 1 次造訪、2 次頁面瀏覽。重新整理也會增加頁面瀏覽量。另開分頁或重開瀏覽器可能算另一次造訪，所以造訪次數不等於實際人數。

比例怎麼算？

分母是所選時間內進入首頁的造訪次數；分子是其中曾看見該區塊或滑到該位置的造訪。同一次造訪的重複互動不會重複增加比例。各區塊分開計算，不是必須依序完成的步驟。

點擊行動

看完之後，觀眾做了什麼？

先看有沒有點進 IG、YouTube，再看文章裡的按鈕或下載。以下顯示操作次數，同一次造訪可以操作多次。

社群連結

點進 Instagram 或 YouTube，不代表已追蹤或訂閱；網站只能記錄連結被點擊。

文章與下載

文章瀏覽代表打開文章，無法判斷是否讀完。尚未提供文章或下載時，顯示 0 是正常的。

設定：排除自己的瀏覽

首次進入後台會自動啟用。手機、其他瀏覽器及無痕視窗須各自設定；清除網站資料後需重新啟用。只影響之後的本站後台資料，既有紀錄無法可靠辨認哪些是你本人，Cloudflare 的獨立報表也不受此開關控制。

這份數據有哪些限制？

「全部」指資料庫目前保留的紀錄。造訪次數不等於不重複人數；廣告攔截、離線或傳送失敗都可能漏記。本頁使用本站事件資料，與 Cloudflare Web Analytics 的計算方式不同。讀取失敗會顯示錯誤，不會用 0 取代。
